# Rock-Paper-Scissors-TOP
    Rock, paper, scissors is a very popular hand game that consists of choosing between rock, paper, scissors, usually played to settle minor decisions.
    This game is a part of The Odin Project curriculum and was made using HTML, CSS and Javascript.

# Rules

- Rock Beats scissors.
- Scissors beat paper.
- Paper beats rock.
- If both players throw the same object, it's a tie. This doesn't count towards the final score.
- Whoever gets to 5 wins is crowned the winner.
